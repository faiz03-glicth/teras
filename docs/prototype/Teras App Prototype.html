Try it

  • Open the Workout tab and tap Start empty workout, or start one of your routines.
  • Tap Add exercise: search (try bench, curl, ohp), or filter by equipment and muscle. Tapping a row adds it.
  • In the muscle filter, tap a muscle on the body to see its exercises.
  • Log like Hevy: each set is a row of Previous · weight · Reps. Tick ✓ to save it and start the rest timer.
  • Tap ⓘ or an exercise name for its muscle map, records and history.

About this screen

    All screens

    Every screen in Parchment (light) and Walnut (dark), rendered from the same components and state as the prototype. Both themes share one token set; only the values change.

    Design system

    The tokens, type scale and components the prototype is drawn with. The colours come from the Kingdom Rush UI kit's wood, parchment, gold and iron, sampled from its screens. Inter is kept to match Streak.
